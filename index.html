진화력PRO — 몸속 표본실

ANATOMY NOIR × LAB. 몸 밖은 밝은 실험실, 몸 안은 어두운 표본실. 모든 정보는 표본 라벨처럼 붙인다.

0. 한눈에 (얼개)

  1. 컨셉: "MRI는 사진, 우리는 비디오". 밝은 실험실(BLISS 토크)에서 설명하다가, 몸속(어두운 인서트)으로 들어가 보이지 않던 움직임을 꺼내 보여준다
  2. 컬러: 2개 모드. LAB(밝은 스튜디오 위) = 잉크 글자 / BODY(어두운 인서트·타이틀) = 본 아이보리 글자. 공통 강조 바이탈 레드 1개, 라벨·선은 스캔 블루
  3. 폰트: Paperlogy 하나로 제목·자막 전부 + 라벨은 IBM Plex Mono(영문 대문자)
  4. 자막: 말자막은 어썸블리스 채널 기존 말자막(FCP '반응형 자막': 흰 박스 + 진회색 OT옴니고딕B) 그대로 · 효과자막은 "표본 라벨" 문법
  5. 인트로: 코스 인트로(몸속 탐사 → 전신 공개 → 로고) 1개 + 주차 오프너 6초
  6. 트랜지션: 3종만. 스캔 와이프 / 블러 블링크 / 하드컷
  7. 아웃트로: 미션 카드 → 다음 주 예고 → 엔드 락업
  8. BGM: 강의 중엔 거의 안 들리는 앰비언트 펄스, 인트로·주차 전환에서만 존재감
  9. 인서트 5종: ① 3D 해부(블렌더) ② 개념 다이어그램(애펙) ③ 리서치 카드 ④ 비유 일러스트(제미나이 2톤) ⑤ 실사 B롤
  10. 촬영: 새 스튜디오(밝은 흰 벽·책상·맥북·붐마이크) 그대로. 정면 중앙, 좌우 흰 벽이 효과자막 자리

1. 컨셉

한 줄: 진화력PRO는 "몸속 표본실"이다. 유튜브 진화력이 짧고 센 정보라면, PRO는 조명 꺼진 실험실에서 BLISS가 몸을 한 겹씩 열어 보여주는 6주짜리 관찰 기록이다.

대본의 세 기둥이 그대로 디자인 규칙이 된다.

대본의 메시지디자인 규칙
"MRI는 사진, 몸은 비디오" (1주차)정지 → 움직임. 인서트는 멈춘 상태로 시작해 반드시 움직이며 끝난다. 정지 그래픽 금지
"보이지 않는 것들" (6주차), 보상작용·패턴어둠에서 꺼낸다. 모든 화면은 어둠이 기본, 필요한 것만 빛을 받는다(림라이트·스캔라인)
몸 밖 vs 몸 안 (새 스튜디오)밝음 ↔ 어둠. BLISS가 말하는 밝은 실험실이 '몸 밖', 인서트·타이틀의 어둠이 '몸 안'. 토크 → 인서트 전환 = 몸속으로 들어가는 문(스캔 와이프)
아기 발달 순서 = 회복 순서표본 번호 체계. W00~W06을 표본 번호처럼 붙이고, 매주 몸의 한 부위가 '켜진다'(W2 횡격막, W3 고관절…)

톤 키워드: 시네마틱 / 임상적 정확함 / 귀여운 손글씨 없음 / 과장된 효과음 없음 / 웃음 포인트는 대사로만

레퍼런스 감: 파이트클럽 오프닝(몸속 탐사) · 넷플릭스 다큐 타이틀(Explained, Human: The World Within) · 의학 일러스트의 라벨 선

  • 한 화면에 VITAL은 한 곳만. 강조가 둘이면 아무것도 강조가 아니다
  • SCAN은 '측정·라벨·구조' 전용: 라벨 선, 각도, 숫자 눈금, 진행바
  • 근육은 실사 톤(인트로와 같은 젖은 붉은 근육). UI 색으로 근육을 칠하지 않는다
  • LUT: 새 스튜디오는 밝고 깨끗하게. 흰 벽이 날아가지 않게 하이라이트만 살짝 누르고, 색온도는 약간 차갑게(실험실 느낌). 인서트(어둠)와 붙었을 때 온도 차이가 '몸 밖 ↔ 몸 안'을 만든다

9. 토크 촬영 가이드 (새 스튜디오)

  • 그대로 쓰는 것: 밝은 흰 벽, 책상 + 맥북 + 붐마이크, 정면 중앙 구도. 이 '밝은 실험실'이 몸 밖 장면이 된다
  • 여백: 좌우 흰 벽이 효과자막·로워서드 자리. 카메라를 지금보다 살짝 넓게(헤드룸 유지, 좌우 벽 더 보이게) 잡으면 그래픽 공간이 생김
  • 노출: 흰 벽이 하얗게 날아가지 않게 노출 −⅓스톱. 얼굴 기준으로 맞추고 벽은 밝은 회백색으로
  • 카메라: A캠 정면 4K(펀치인 여유), B캠 45° 측면(인서트에서 돌아올 때 컷 전환용)
  • 의상: 지금 같은 밝은 회색 무지 티 좋음(LAB 톤). 로고·패턴만 피하기
  • 소품: 맥북 로고가 정면 하단에 크게 보임 → 스티커로 가리거나 맥북 각도 조절. 해부 모형(척추·골반) 하나 책상 위에
  • 오디오: 지금 붐마이크(Shure MV7 류) 유지 + 핀마이크 백업, 룸톤 30초
  • 라이브 운동: 같은 스튜디오 바닥, 전신 와이드 + 디테일 캠
